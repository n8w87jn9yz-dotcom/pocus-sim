# Menschmodell für die Halte-Bilder

`body.bin` ist das MakeHuman-Grundmodell (`makehuman/data/3dobjs/base.obj` aus github.com/makehumancommunity/makehuman),
vom Rechteinhaber 2020 unter CC0 freigegeben. Umgewandelt mit `convert_makehuman.py`, nur zum Rendern von `data/hold/*.webp`
(`tools/render_holds.cjs`), wird nicht mit ausgeliefert.
